# Image credits

Photographs and paintings added to the picture-based demo websites. One file
per demo, listing each image, what it shows, where it came from, its creator
and its licence.

Sources used:

- **Unsplash** — Unsplash licence: free to use commercially, no attribution
  required. Paid "Unsplash+" images were not used.
- **Wikimedia Commons / Openverse** — only files marked CC0 or public domain.

Attribution is not required for any of these, but the records are kept so
every image can be traced. Creator names and page addresses for some Unsplash
photos were read from search listings rather than from the photo's own page,
so spot-check them before quoting a credit publicly.

The template-based demos use the stock media that came with the template
bundle; those are not listed here.
