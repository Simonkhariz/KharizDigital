Kravio support dashboard.

This folder is the built (ready-to-serve) version of the dashboard, copied
from the Dashboard folder in the project's top level. Its file addresses were
changed from /assets/... to /demos/kravio/assets/... so it can be served
from this sub-folder, and a "Khariz Digital" back link was added to
index.html. To update it, replace these files with a new build and repeat
those two changes.
